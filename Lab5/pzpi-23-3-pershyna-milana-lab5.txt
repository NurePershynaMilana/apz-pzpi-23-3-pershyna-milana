2 ЗАВДАННЯ
Підготовка презентації завершеного проєкту PlantCare System - автоматизованої системи догляду за кімнатними рослинами на базі IoT, розробленої протягом двох семестрів. Презентація включає демонстрацію основних функцій системи, порівняння запланованого та виконаного функціоналу, а також матеріали у вигляді слайдів і відеодемонстрації.


3 ОПИС ВИКОНАНОЇ РОБОТИ
Опис проєкту
PlantCare System - це програмна система автоматичного догляду за кімнатними рослинами. Вона відстежує ключові параметри навколишнього середовища через мережу IoT-датчиків і автоматично підтримує оптимальні умови для кожного виду рослини. Система складається з чотирьох компонентів: серверної частини на Node.js з PostgreSQL, веб-застосунку на React.js, мобільного застосунку на Kotlin та IoT-клієнта на ESP32.
Усі компоненти взаємодіють через захищений REST API з JWT-автентифікацією. IoT-пристрій кожні 20–30 секунд збирає дані з датчиків і надсилає телеметрію на сервер, який аналізує показники та повертає відповідні команди — полив, освітлення або регулювання температури. Веб і мобільний клієнти відображають поточний стан рослин у реальному часі та надають можливість керувати системою вручну.


Заплановані та виконані функції
У ході двох семестрів роботи було повністю реалізовано основний запланований функціонал системи. На серверній частині реалізовано REST API з JWT-автентифікацією та рольовою моделлю, документацію через Swagger, контейнеризацію за допомогою Docker та автоматичний деплой через GitHub Actions. IoT-клієнт на ESP32 підтримує всі заплановані сценарії автоматичного реагування. Мобільний застосунок на Kotlin з Jetpack Compose реалізовано з повним функціоналом, включаючи push-сповіщення та налаштування режимів. Веб-застосунок містить дашборд, адміністративну панель, генерацію PDF-звітів, локалізацію двома мовами та резервне копіювання даних.
Частина функцій була свідомо виключена зі скоупу проєкту. Офлайн-режим IoT не реалізовувався навмисно — це архітектурне рішення на користь централізації логіки на сервері. iOS-версія мобільного застосунку була виключена через обмеження ресурсів. Комп'ютерний зір у реальному часі та мультилокаційність також не увійшли до поточної версії. Інтеграція штучного інтелекту через OpenAI API запланована як наступний крок розвитку системи.
Матеріали презентації
Презентація підготовлена у форматі слайдів (13 слайдів) та охоплює: загальний опис проєкту та його мету, стек технологій і архітектуру системи, детальний опис кожного компонента (сервер, веб, мобільний застосунок, IoT-клієнт), порівняння запланованого та виконаного, а також висновки.


4 ВИСНОВКИ
У ході двох семестрів роботи реалізовано повноцінну IoT-систему PlantCare System з чотирьох компонентів. Розроблено RESTful API з документацією Swagger, мобільний застосунок на Kotlin з Jetpack Compose, веб-застосунок на React.js з аналітикою та адміністративними можливостями, а також IoT-клієнт на ESP32, що автоматично реагує на стан рослин. Весь запланований функціонал реалізовано у повному обсязі; частина можливостей була свідомо виключена з огляду на архітектурні рішення або обмеження ресурсів. Система готова до розширення — наступним кроком є інтеграція штучного інтелекту для персоналізованих порад з догляду за рослинами.

У презентації завершеного проєкту потрібно описати, що з запланованого було реалізовано, а що - ні. Є список функцій: REST API, IoT-клієнт, мобільний застосунок, веб-застосунок, PDF-звіти, локалізація, резервне копіювання. Також є функції, які свідомо не реалізовувались: офлайн-режим IoT, iOS-версія, комп'ютерний зір, мультилокаційність. Як краще структурувати цей розділ, щоб виключені функції не виглядали як недоробки, а як усвідомлені архітектурні рішення?

Отримана відповідь:
Рекомендовано розділити опис на дві частини: реалізований функціонал та свідомо виключений. Для виключених функцій запропоновано чітко вказувати причину - архітектурне рішення, обмеження ресурсів або перенесення на наступний реліз. Такий підхід демонструє зрілість у прийнятті проєктних рішень і показує, що скоуп проєкту контролювався свідомо, а не хаотично скорочувався. Запропоновані формулювання були адаптовані та включені до відповідного розділу звіту.

Запит (prompt) щодо формулювання elevator pitch для системи PlantCare:
Розробила IoT-систему догляду за рослинами PlantCare System з чотирьох компонентів: Node.js сервер, React веб-застосунок, Kotlin мобільний додаток та ESP32 IoT-клієнт. Потрібно сформулювати короткий elevator pitch системи як продукту для клієнтів - на 3-4 речення, щоб зрозуміло і переконливо пояснити цінність системи звичайному користувачу, не технічному спеціалісту.

Отримана відповідь:
Запропоновано наступне формулювання: PlantCare - це розумна система, яка доглядає за вашими рослинами замість вас. Датчики постійно відстежують вологість ґрунту, температуру та освітлення, а пристрій автоматично поливає рослини та регулює умови без будь-якого втручання з вашого боку. Через мобільний застосунок або веб-браузер ви бачите стан кожної рослини в реальному часі та отримуєте сповіщення, якщо щось потребує уваги. Більше ніяких засохлих рослин через забудькуватість або відпустку. Формулювання було адаптовано під технічний контекст звіту та скорочено відповідно до формату презентації.
